# Szufladka – support and privacy pages

The public pages of Szufladka, an iPhone and iPad app for Polish receipts, vouchers and warranties, published with
GitHub Pages for its App Store listing:

- Support: https://m-czupryna.github.io/szufladka-site/
- Privacy policy: https://m-czupryna.github.io/szufladka-site/privacy/

The app's code lives in a private repository. `privacy.md` is a word-for-word copy of that repository's
`docs/PRIVACY.md` (the same texts the app bundles); change it only together with it.
